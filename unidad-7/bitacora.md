### **Palabra elegida: "WRONG" → "HARMONY" (transformación)**

#### **Justificación conceptual:**
La pieza narra un viaje desde la disonancia (WRONG) hacia la armonía (HARMONY), inspirada en la pieza de Chopin donde una "nota equivocada" genera tensión que eventualmente resuelve en belleza. el código  tiene esta progresión por etapas.

### **Mapa de Decisiones para tu bitácora:**

| Dimensión | Decisión | Por qué refuerza el significado |
|-----------|----------|--------------------------------|
| **Palabra** | WRONG → HARMONY (evolución) | La "nota equivocada" busca resolución |
| **Tipografía** | Condensada (tensión) / Expandida (armonía) | La forma visual expresa presión vs libertad |
| **Física** | Fragmentación + vibración | El error genera caos visible |
| **Audio** | Transientes = "sacudidas" | Las notas disonantes alteran el sistema |
| **Interacción** | Mouse = "mano del intérprete" | El performer puede aumentar o calmar la tensión |
| **Color** | Rojo (caos) → Azul (armonía) | Gradiente emocional visual |



1. **Palabra elegida:** "WRONG" transformándose en "HARMONY"
2. **Significado:** La tensión de una nota equivocada que busca su resolución natural
3. **Relación física-audio:** 
   - Transientes musicales → fragmentación visual
   - Acordes menores → mayor caos
   - Armonía creciente → orden y calma
4. **Interpretación en vivo:** 
   - El mouse puede perturbar o calmar
   - La música dicta el estado emocional
   - El performer "conduce" el viaje del caos a la armonía
